오른쪽 그림과 같이 두 직선이 한 점에서 만날 때 생기는 4개의 교각 ∠a, ∠b, ∠c, ∠d 에서 마주 보는 각의 크기가 왜 항상 같은지 단계별로 이유를 밝혀 봅시다.
1
1단계: ∠a 와 ∠c 의 크기 비교하기
직선이 이루는 각(평각)의 크기를 이용하여 빈칸을 채워보세요.
∠a + ∠b = 180°, ∠b + ∠c = ° 이므로
∠a + ∠b = ∠b + ∠c (두 식의 합이 모두 180°로 같음)
즉, 양변에서 공통인 ∠b 를 빼면: ∠a = ∠ 이다.
2
2단계: ∠b 와 ∠d 의 크기 비교하기
같은 방법으로 마주 보는 두 각 ∠b와 ∠d의 크기가 같은 이유를 알아봅시다.
∠b + ∠c = 180°, ∠c + ∠d = ° 이므로
∠b + ∠c = ∠c + ∠d , 즉 ∠b = ∠ 이다.
3
3단계: 1, 2에서 알 수 있는 점 정리하기
1번과 2번에서 알아본 내용을 바탕으로 수학적 성질을 완성해 보세요.
Q1. 두 직선이 한 점에서 만날 때 생기는 서로 마주 보는 각을 무엇이라고 할까요?
Q2. 1단계(∠a = ∠c)와 2단계(∠b = ∠d)의 결과에 따라, 맞꼭지각의 크기는 서로 어떠한가요?

🎉 맞꼭지각의 성질을 완벽하게 발견했어요!

두 직선이 한 점에서 만날 때 서로 마주 보는 각을 맞꼭지각이라고 하며,
"맞꼭지각의 크기는 항상 서로 같다"는 것을 평각(180°)의 성질과 등식의 성질을 통해 스스로 완벽하게 밝혀냈습니다!

📖 교과서 한눈에 정리하기

[맞꼭지각의 정의]
두 직선이 한 점에서 만날 때 생기는 4개의 교각 중, 서로 마주 보는 두 각을 맞꼭지각이라고 합니다.

■ 맞꼭지각의 크기가 같은 이유 (설명 과정)

1. ∠a 와 ∠c 의 크기 비교
• 직선 위의 두 각의 합은 평각(180°)이므로:
  ∠a + ∠b = 180°,  ∠b + ∠c = 180°
• 두 식의 합이 같으므로: ∠a + ∠b = ∠b + ∠c
• 양변에서 공통인 ∠b 를 빼면: ∠a = ∠c
2. ∠b 와 ∠d 의 크기 비교
• 마찬가지로 평각(180°)의 성질에 의해:
  ∠b + ∠c = 180°,  ∠c + ∠d = 180°
• 두 식의 합이 같으므로: ∠b + ∠c = ∠c + ∠d
• 양변에서 공통인 ∠c 를 빼면: ∠b = ∠d
✨ 결론: 맞꼭지각의 크기는 서로 같다!
